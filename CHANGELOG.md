# Changelog

## v0.3.0 — 2026-08-24

- Added research-article workflows for abstracts, contribution maps, related work, methods,
  results, referee reports, and responses to reviewers.
- Added a source-and-derivation audit with issue classification, correction authority, a correction
  ledger, and explicit verification verdicts.
- Added text-, source-, execution-, and render-bound artifact verification.
- Added a quantitative-finance profile covering measure changes, martingale densities,
  no-arbitrage, replication, admissibility, calibration, and identification.
- Made the working register compact and conditional for routine light edits while retaining it for
  material changes and traceable audits.
- Packaged the accepted twelve-file v0.3.0 runtime core as a public-safe distribution.

The private corpus, blind fixtures, evaluator outputs, signing material, and full release harness
remain excluded.

## v0.2.0 — 2026-07-27

- Added a source-grounded working register for notation, claims, support, evidence level, site, and
  citation.
- Added claim siting and repetition controls.
- Added evidence-matched verbs for proofs, derivations, examples, figures, simulations, and data.
- Added functional anti-defensive review with protection for mathematical negation and genuine
  limitations.
- Added Draft, Revision, Review, Verification, and Visual Companion output contracts.
- Added the MATH3015 visual-companion profile.
- Published the accepted eight-file runtime core as a public-safe distribution.

The private development corpus, blind fixtures, source-derived notebook samples, signing material,
and full release harness are intentionally excluded from the public repository.
