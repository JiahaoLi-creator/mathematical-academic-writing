# Changelog

## v0.2.0 — 2026-07-27

- Added a source-grounded working register for notation, claims, support, evidence level, site, and
  citation.
- Added claim siting and repetition controls.
- Added evidence-matched verbs for proofs, derivations, examples, figures, simulations, and data.
- Added functional anti-defensive review with protection for mathematical negation and genuine
  limitations.
- Added Draft, Revision, Review, Verification, and Visual Companion output contracts.
- Added the MATH3015 visual-companion profile.
- Published the accepted eight-file runtime core as a public-safe distribution.

The private development corpus, blind fixtures, source-derived notebook samples, signing material,
and full release harness are intentionally excluded from the public repository.
